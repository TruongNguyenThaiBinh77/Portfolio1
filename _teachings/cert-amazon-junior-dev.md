Chứng chỉ chuyên nghiệp do tập đoàn **Amazon** chứng nhận thông qua nền tảng Coursera, bao gồm 7 khóa học chuyên sâu:
1. Introduction to Software Development
2. Programming with Java
3. Data Structures and Algorithms
4. Database Management with Java and SQL
5. Full Stack Web Development
6. Generative AI in Software Development
7. Application Development

Chứng chỉ khẳng định năng lực lập trình Java hướng đối tượng, làm chủ quy trình phát triển web full-stack, thao tác cơ sở dữ liệu và tích hợp công nghệ AI tạo sinh trong xây dựng ứng dụng phần mềm hiện đại.
